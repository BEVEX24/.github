# Padrões da organização BEVEX24

Este repositório centraliza o perfil público, os documentos de comunidade e o design system compartilhado. Repositórios públicos da organização herdam os arquivos compatíveis do repositório `.github` quando não possuem uma versão própria.

O padrão universal compartilha arquitetura, componentes, acessibilidade e comportamento. Cada sistema mantém identidade visual própria, definida pela área de atuação: BEVEX24 em ciano, LabFlow com referências laboratoriais e FactoryFlow em âmbar industrial.
