# Governança de engenharia

## Proteção recomendada para `main`

- Pull request obrigatório, com ao menos uma aprovação.
- CI obrigatório e branch atualizada antes do merge.
- Conversas de revisão resolvidas.
- Force push e exclusão bloqueados.
- CODEOWNERS para banco, autenticação, fiscal, segurança e workflows.
- Merge por squash; branches removidas após o merge.

As regras de configuração do GitHub devem refletir este documento. Exceções operacionais precisam ser temporárias, registradas e revisadas.
